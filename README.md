# lecture-extract — ローカル講義動画テキスト化システム

ダウンロード済みの講義動画から、**画面に表示されたスライド本文・コード・実行結果**と、
**講師の発話**を抽出し、時系列で読める Markdown と再加工用の構造化データを作ります。

`local_lecture_extraction_design.md`（版 0.1）の設計に沿った実装です。段階 0〜3 の範囲を実装しています。

初回のソフトウェア・モデル取得を終えたあとは、解析から出力まで**ネット接続なしで完結**します。
有料サービス・クラウド API を使いません。

---

## 何をするか

- 画面の表示内容が続く期間をひとつの **表示状態** として切り出す
- その期間の画面全文を、ローカル VLM（llama.cpp + Qwen3-VL）で転記する
- 発話をローカル ASR（whisper.cpp + Whisper large-v3-turbo）で文字起こしする
- 表示期間と発話を、**区間の重なり**で対応づける
- 原文を書き換えずに Markdown・JSONL・SRT へ出力する

## 何をしないか

設計 1.2 の「抽出と解釈の分離」をそのまま実装しています。

- スライドの原文を要約・翻訳しない
- コードを正しい形に修正したり、画面外の行を補完したりしない
- 発話を自然な説明文へ書き換えない
- 判読できない箇所を推測で埋めない（不明として残し、候補は原文と別の欄に置く）
- 処理が終わったことを「全文検証済み」と表示しない

## 導入

**[docs/SETUP.md](docs/SETUP.md) に、この PC での具体的な手順があります。**

```bash
py -3.12 -m venv .venv
.venv/Scripts/python.exe -m pip install -e .
.venv/Scripts/lecture-extract.exe doctor   # 不足しているものを一覧表示
```

必要なもの:

| 種類 | 内容 |
|---|---|
| ソフトウェア | Python 3.12+、FFmpeg / ffprobe、llama.cpp（llama-server）、whisper.cpp（whisper-cli） |
| モデル | Qwen3-VL-8B-Instruct GGUF（Q4_K_M）＋ mmproj、Whisper large-v3-turbo（ggml 形式） |

## 実行

```bash
lecture-extract run "D:/lectures/week01.mp4" -o out/week01 \
  --vision-model models/qwen3-vl-8b/<MODEL>.gguf \
  --mmproj models/qwen3-vl-8b/<MMPROJ>.gguf \
  --manage-vision-server \
  --asr-model models/whisper/ggml-large-v3-turbo.bin \
  --language ja
```

### 主なコマンド

| コマンド | 用途 |
|---|---|
| `run` | 解析して出力まで行う。中断後は同じコマンドで再開する |
| `probe` | 時刻基準・ストリーム情報・タイムスタンプ異常を確認する |
| `doctor` | 必要なソフトウェアとモデルの不足を一覧表示する |
| `status` | ステージの進捗、表示期間・発話・未解決の確認項目の件数 |
| `export` | 正本（SQLite）から出力を作り直す |
| `review list` / `review resolve` | 未確定箇所の確認と処理 |
| `cache` | 画像キャッシュの容量確認・整理・根拠画像の再生成 |
| `correct` | 領域の原文を手修正する（元の抽出結果は残す） |

### 主な選択肢

| 選択肢 | 意味 |
|---|---|
| `--mode preserve`（既定） | 全フレームを復号して変化候補を拾う。一瞬の変更を残すことを優先する |
| `--mode fast` | 2fps 程度から始める試用・概算向け。取り逃がしがありうるため「検証済み」とは表示しない |
| `--start` / `--end` | 区間を限定する。出力の時刻は元動画に対する時刻に戻る |
| `--only` / `--force` | ステージを限定する / 完了済みでも再実行する |
| `--channel left` など | ステレオの単純平均で音声が消える場合にチャンネルを選ぶ |

## 出力

| ファイル | 内容 |
|---|---|
| `lecture.md` | 表示期間ごとの画面全文と発話。コードはコードブロック、発話は個別時刻付き |
| `blocks.jsonl` | 読書ブロックと表示状態・発話の参照 |
| `screen_contents.jsonl` | 画面本文、領域、構造、抽出状態 |
| `screen_occurrences.jsonl` | 表示の開始・終了、本文 ID、根拠、変更状態 |
| `utterances.jsonl` | 原文の発話と時刻（原文は 1 度だけ保存し、参照で結ぶ） |
| `transcript.srt` | 発話だけの字幕。画面 OCR の文は混ぜない |
| `quality_report.md` | 未抽出区間、不明文字、時刻異常、要確認項目、性能計測 |
| `manifest.json` | 入力ハッシュ、モデル・実行環境・設定・出力バージョン |
| `work/state.sqlite` | 再解析・再開のための内部正本 |

Markdown には画像を埋め込みません。根拠画像は `work/frames/` に、モデルの原応答は
`work/responses/` に残り、SQLite から参照できます。

## 設計上の要点

- **時刻**: すべて元動画の再生開始（t0）を基準とする整数マイクロ秒。時刻は PTS × time_base から求め、
  「フレーム番号 ÷ 公称 FPS」は使いません。可変フレームレートと音声開始オフセットに対応します。
- **境界は推定**: 表示の切り替わりは、旧状態を最後に観測した時刻と新状態を最初に観測した時刻の
  両方を保存します。単一の確定値としては扱いません。
- **小さな変更を落とさない**: 全体差分だけでなくタイルごとの局所差分と変化画素の実数で判定します。
  コード 1 文字の変更を検出し、カーソル点滅は視覚イベントとして分離します。
- **短時間表示も残す**: 0.5 秒未満の表示も期間として保存し、認識できなかった場合は
  「短時間表示・全文未確定」として残します。最終状態だけを残して途中を消すことはしません。
- **重複表示**: 同じスライドが再登場した場合、本文は 1 件に集約し、出現（表示期間）は別に残します。
- **中断・再開**: 段階と処理単位ごとに完了状態を保存します。入力・設定・モデルのハッシュを比較し、
  必要な部分だけを再解析します。
- **ローカル限定**: 推論サーバーの接続先は 127.0.0.1 に限定します。外部推論サービスへの
  自動切り替えは実装していません。抽出したコードは文字データとして扱い、実行しません。

対応表は [docs/DESIGN_TRACE.md](docs/DESIGN_TRACE.md) にあります。
実動画での実測値と、見つかった問題・未確認事項は [docs/RUN_NOTES.md](docs/RUN_NOTES.md) にまとめています。

## 試験

モデルを使わずにパイプライン全体を検証できます。合成講義動画を生成し、
画像へ埋め込んだマーカーから台本を引くアダプターで抽出を代替します。

```bash
.venv/Scripts/python.exe -m pytest
```

設計 14.3「優先する検証」に対応する項目を試験しています。

- カーソル点滅だけでは文字変更にしない
- コードの 1 文字の変更を落とさない
- 同じスライドの再登場を別の表示期間として残す
- 編集前と編集後のコードを混ぜて結合しない
- 画面境界をまたぐ発話を両側から参照できる
- チャンク境界で発話が消えたり二重化したりしない
- 中断前後で確定結果の欠落・二重登録が起きない
- 処理状態が不明な区間が残らない
